## 1. 接口决定

- **身份**（`crates/domain/src/ids.rs`）：载荷固定 16 字节（`ID_LEN`），规范文本为 32 个小写十六进制字符（`ID_HEX_LEN`），解析同时接受大写，因此同一值只有一种字节表示。类型：`ServerId`、`RootId`、`BindingId`、`EntryId`、`VersionId`、`DeviceId`、`OpId`（design §7.1 列出的身份，`ContentHash` 除外）。统一接口 `from_bytes`（`const fn`，供常量身份与平台 blob 使用）、`as_bytes`、`from_hex`、`to_hex`、`generate`，并实现 `Display`/`Debug`（`EntryId(hex)`）/`FromStr`/`Ord`/`Hash`。长度取 16 字节是**兼容性决定**：`crates/platform-windows` 的 CFAPI `FileIdentity`（48 B = magic+版本+RootId 16+EntryId 16+提示 8+CRC 4）只留 16 字节给 RootId/EntryId，服务端分配的 ID 因此可直接写入平台身份，不需要第二套映射。
- **未实现 `ContentHash`**：DESIGN §7.1 列出它，但它是内容 SHA-256（`crates/transfer/hash.rs` 的落点），不是身份或计数；本卡不预置占位，`crates/platform-windows`/`platform-linux-server` 已有零依赖 SHA-256 可复用。
- **解析错误** `IdParseError`：`Empty`、`Length(实际字节数)`、`NonHexDigit(0 基字节位置)`。长度不符即返回 `Length`，不再逐字符检查，故 `0x…`、带连字符 UUID 文本都报 `Length`；`" 0112…"`、非 ASCII 32 字节等报 `NonHexDigit`。
- **注入端口** `IdSource { fn next_id_bytes(&mut self) -> [u8; ID_LEN] }`：domain 不取随机数（design §5.4），生产端在应用层接线，测试注入计数器即完全复现。
- **计数**（`crates/domain/src/version.rs`）：`Revision`、`RootSeq`、`Generation`（§15.3 的 `local_generation`）、`ServerEpoch`，均为 `u64` newtype，不变式 `0..=DB_INTEGER_MAX`（`i64::MAX`，SQLite `INTEGER` 有符号 64 位上限）。接口 `ZERO`、`new`、`from_db_integer`、`to_db_integer`、`get`、`next`、`from_decimal`、`to_decimal`。`next` 到达上限返回 `AboveDbLimit`，不回绕。四者是不同类型，不能互相赋值。
- **`ServerEpoch` 按有界计数建模**：design §15.3 的 `"epoch_example"` 只是示意字符串（同段说明“ID 为示例字符串”），而 §7.2 `roots` 表的 `seq`/`epoch` 是数值列、§9.4 只要求 epoch 可比较且恢复后更换。作为计数器可同时满足“字符串传输”“落库 i64”“不重放旧 epoch”，故按本卡“有界计数”分组实现；若后续协议冻结要求不透明 token，只需替换该 newtype 的载荷，调用点（`to_decimal`/`from_db_integer`）已集中在类型内部。
- **错误** `BoundError`：`Empty`、`InvalidDigit`、`Negative`、`LeadingZero`、`AboveDbLimit`；解析用 `checked_mul`/`checked_add` 累加，19 位以上数值报 `AboveDbLimit`。规范十进制无符号、无前导零，`0` 写作 `"0"`；`+1`/空白/小数点/下划线报 `InvalidDigit`，`-1` 报 `Negative`。
- **时间**：`UtcTimestamp`（Unix 秒 `i64`，负值报 `Negative`）与 `Clock { fn now_utc(&self) -> Result<UtcTimestamp, BoundError> }`。系统时钟不可信（例如早于 1970）必须报错而不是编造时刻。本卡没有带时间字段的类型，端口只提供注入点，不预建其它时间 API。

- 无真实随机源实现：`IdSource` 目前只有测试内的计数器实现，OS 随机接线属应用/适配层卡。

- 未验证 `ServerEpoch` 与备份恢复流程的联动（无恢复实现）。
