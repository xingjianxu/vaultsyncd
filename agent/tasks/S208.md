# S208 — Web 文件浏览器 PDF 与图片在线预览

状态：in_progress（实现、浏览器验收与独立复审完成，待纯构建/部署、交接和合并清理）。用户2026-11-12要求在线浏览PDF、图片；规范 design §18.1/24 ADR-019补充，接口文档S122。前置S171/S145/S206；不改变Windows客户端或发行。

## 实现与边界

文件名点击/右键「预览」打开Mantine Modal；PDF翻页及50/100/150/200%缩放，PNG/JPEG/GIF/WebP/BMP/AVIF静态画面，保留原文件下载、取消、关闭/Escape和错误重试；其他类型仍显示属性。复用 `downloadFile`/BrowserAuth 冻结版本、Range长度及完整SHA-256；关闭、导航、换Vault/会话及卸载取消并忽略迟到。无wire/数据库迁移，不读服务器任意路径。

`pdfjs-dist@6.5.438` 精确锁定，可信worker及185字体/CMap同源随包交付。只画canvas，不建立HTML/SVG、表单、注释/链接或脚本层，不放宽CSP。网络前50 MiB，栅格及PDF单幅解码16 Mi像素/单边8192，canvas 8 Mi像素；这些是分项预算，不宣称整个浏览器总内存恒定。密码PDF不提供输入，提示下载后打开；动画图仅静态帧，SVG/HTML不预览。
