# S196 — 统一默认排除与绑定附加规则

状态：done。用户明确要求：桌面「完整排除清单」应只是**额外**规则，内置默认清单始终加载（含 Office `~$*` 锁文件）。设计入口 design §10.4/§18.1、ADR-035；直接前置 S018/S061/S082；子范围 [S196-a](S196-a.md)（core/运行时/首次导入）、[S196-b](S196-b.md)（桌面/IPC/原生验收）。

有效规则统一为「内置默认 + 绑定附加」：`fs-common::DEFAULT_RULES` 是唯一默认源，`parse_with_defaults` 用于运行时、规则解释、保存校验与首次导入；绑定的持久文本原样保存附加规则，空文本不关闭默认排除，后置 `!` 仍可重新包含。已有绑定的语义变更由客户端迁移 0017（`default_rules_version`）栅栏与一次幂等采用覆盖：签发新规则版本、使旧 ACK/完整证明失效、按有效规则刷新参与状态；旧二进制拒绝新库，回退恢复整套 schema16 备份。首次导入不再为排除条目建本地 staging 行或留在后台队列（意图/ACK/字节仍留在 journal），但仍保留完整认证远端事实，供无新事件时重新包含恢复。

修复了 S196 独有的两个卡死路径：排除停放的操作不再阻塞无关文件的 full 补齐（`exclusions::unsettled` 只计当前参与者），排除期间被本地删除的**已跟踪**文件保持协调围栏、不自动重下也不推导远端删除；远端从未跟踪的条目受控恢复（按需绑定只建占位），目录父先子后。本机 IPC 升至 **3.0**（`rules` 语义变化，拒绝 2.x 混用），远端 HTTP 不变；桌面文案改为「额外排除规则」并说明默认加载与 `!`。
