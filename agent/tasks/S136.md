结果：`#/files` 支持工具栏上传/当前目录粘贴、行与空白区右键菜单（打开/属性/复制路径/复制/剪切/粘贴/删除）、删除确认与回收站语义；剪贴板与任务跨目录/Root/管理页保留。上传走完整摘要→服务端块几何→块摘要→finalize→`create(expected_absent=true)`；复制按固定快照/版本逐项新建并父先子后，不覆盖同名；同 Root 剪切为 CAS move 保 EntryId，目录不可移入自身/后代；跨 Root 剪切明确拒绝而不自动删源。删除前冻结目录 subtree token 并复核子树，确认过期不自动换范围。`FileActionJob.canDiscard` 只在无未知命名空间提交时允许结束后续；账号隔离 sessionStorage 恢复日志在 submit 前落盘，刷新只查询、404 不视为取消，用户明确确认才用原 request/device/op 重放；认证动作/卸载门禁阻止旧任务追加提交。单文件上传沿用服务端 64 GiB，复制因固定版本客户端完整缓冲限制为 64 MiB。
