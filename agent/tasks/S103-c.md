## 装置与注入

- 平台层：真实 `DirWatcher` 监视真实目录，交替修改两个文件时间戳直到内核 `IN_Q_OVERFLOW`；溢出后写入的事件被内核丢弃，断言上报 `WatchSignal::Overflow` 且补扫后新事件仍可达。
- 观察器层：`FollowDriver` + 真实 inotify + 真实目录；溢出后丢失一次改写，断言一步内立即全量补扫（`FullScanCause::QueueOverflow`），最终采集丢失内容。
- 权限：真实 `chmod 000` 目录 → `Gap`/`PermissionDenied`，不是删除；权限恢复后继续。
- 另外覆盖：保留 mtime 的改写靠周期扫描发现；Root 卸装出空目录 → `RootUnavailable` 零删除；同一真实目录上持续写入会保持等待直到写入者停止。
