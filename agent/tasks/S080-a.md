# S080-a — Windows 壳与安全边界

状态：done，S080 的实现细分，不减少父卡验收。

`apps/desktop/src-tauri` 加入根 Cargo workspace，Tauri 仅为 Windows 目标依赖，不引入 Linux GUI 平台构建。根 Cargo.lock 新增 248 个包，未移除或升级已有锁定版本。build.rs 按目标操作系统生成资源与 AppManifest 权限；正式命令只有 `agent_get_status`，主窗口只有 `allow-agent-get-status`，无远端 capability 或 shell/fs/SQL 插件。CSP 禁止远端脚本、frame、对象和表单，导航仅内置应用来源。

桥返回生成 `GetStatusResult`，只调用 `Endpoint::current("vaultsyncd-agent")`，继承真实 SID/session、对端身份与有界帧/超时；不接受管道名、路径或 shell 参数，不打开数据库。IPC 错误转换为无内部路径的中文错误。托盘打开/退出只控制界面，agent 独立运行。前端默认 nativeAgent，保留显式失败的旧替身供消费测试；状态读取成功才显示“agent 已连接”，不宣称同步完成。

参考已查阅的官方说明：[应用命令权限](https://v2.tauri.app/security/capabilities/)、[托盘](https://v2.tauri.app/learn/system-tray/)。原生运行证据见 S080-b。
