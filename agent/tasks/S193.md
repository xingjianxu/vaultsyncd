# S193 — Windows 客户端移除已保存的服务器

状态：done。实现提交 `c587d78`，本交接提交随后 ff 合入 `master`。

## 目标与用户决定

Windows 桌面「连接设置」中每个已保存服务器提供「移除服务器」。

- 绑定处理（用户 2026-11-11 明确）：仍有**正在管理**的本地 Binding 时拒绝，提示先在「同步目录」解除绑定；不隐式解绑、不删除本地数据。已解除绑定的恢复记录不算“正在管理”，保留且不阻止移除，也不被移除删除。
- 会话与凭据（用户 2026-11-11 明确）：**尽力**调用远端注销；服务器不可达或拒绝时仍删除本地连接、登录资料与 Windows 凭据，并如实告知未确认撤销。

## 实现

- 契约：`api/local-ipc.schema.json` IPC minor 2.10→2.11，新增命令 `remove_connection(server_id)` 与结果字段 `ManagementResult.session_revoked`；`cargo xtask generate` 重生成 Rust/TS，示例与两侧样本计数更新为 29。
- 存储：客户端 schema 15→16，迁移 `0016_connection_removals.sql` 记录已移除身份；`connections::{in_use,removed,remove}` 在 `BEGIN IMMEDIATE` 内检查“正在管理”的绑定（`binding_controls.detached=0`），删除登录资料与连接行并写入留痕。`load_connections` 据此不再把 `agent.json` 旧单连接当后备入口复活。
- agent：`Runtime::remove_connection` 先解析持久连接与绑定前置条件（拒绝时零副作用，含不停止工作者），停止该服务器工作者，再用独立 `Connection` 尽力注销并清除 WinCred 凭据，最后删库并从连接推送中移除。新拒绝码 `CONNECTION_IN_USE`，`ipc.rs` 映射为明确中文说明；IPC ≤2.10 调用方收到 `UnsupportedVersion`。
- 桥与前端：固定 command `agent_remove_connection`（AppManifest + 仅主窗口 capability + `generate_handler`），`AgentClient.removeConnection`；卡片「移除服务器」+ Mantine `Dialog` 二次确认（保持挂载以恢复焦点），取消不发命令，未确认撤销用不自动消失的通知保留。
