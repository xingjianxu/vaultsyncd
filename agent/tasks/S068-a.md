# S068-a — Windows 持续保护与写入检测

状态：done；父卡 S068 的文件端口子范围，不改变验收目标。

`files::controlled` 用正式 `CfOpenFileWithOplock(EXCLUSIVE)` 取得 RH oplock，`ProtectedLease` 在使用 Win32 句柄前 `CfReferenceProtectedHandle`，结束后 release，禁止关闭借用句柄。`WindowsFiles::protect` 在 pinned root/parent no-follow 元数据核对后取得保护，再核对物理身份；部分内容、硬链接、未知 reparse、busy 明确拒绝。非水合 metadata 查询仍用 S065 `RootHandle`，不为判定而水合。

`observe` 在持续有效保护内分块复制至独立状态目录，256 KiB 流式 SHA-256；固定快照句柄拒绝外部写/删除，后续保存不影响快照。`Evidence` 包括物理身份、长度、摘要和本地代际；应用从 durable local 状态 `seed`，首次观察仍核对真实字节，变化只递增 generation，不根据 mtime。watcher 仍只唤醒扫描，不直接确认 clean/删除。

实际 Windows 原生验证见 S068：原地写、普通 ReplaceFile、在线 CFAPI 的 MoveFileEx 原子保存均识别新字节/身份；共享模式 0/1/7 的写者和“创建 file handle 已关闭、可写 section 仍存活”均不能取得保护，保存字节留在原处。未承诺保护编辑器尚未保存的内存，也不宣称所有应用均已验收。
