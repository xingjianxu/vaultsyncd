# S140 — 共享目录概念改名 Vault（核心、wire、数据库、服务端与客户端通用代码）

状态：done；依据 2026-11-08 用户要求与 design §24 ADR-021。范围：把“一个共享目录”的正式名称由 Root 改为 Vault，覆盖标识符、wire 字段与路径、错误码、配置键、数据库表/列/索引、服务端与客户端通用代码、UI 源码中的术语；文件系统根、mount root、root 用户、TLS 信任根与 Windows CFAPI `SyncRoot` 等非本概念的 root 不动。

关键接口决定（详见 `docs/architecture/interfaces.md` 与 ADR-021）：

- Rust：`RootId`→`VaultId`、`RootSeq`→`VaultSeq`、`RootHandle`→`VaultHandle`、`RootSnapshot`/`RootDrift`/`RootFacts`→`Vault*`；模块 `server_store::vaults`、`server_core::api::vaults`、`apps/server::vaults`、`platform_linux_server::files::vault`。
- wire：`root_id`→`vault_id`、`root_seq`→`vault_seq`、`/v1/roots`→`/v1/vaults`、`Root*` schema→`Vault*`、`ROOT_UNAVAILABLE`→`VAULT_UNAVAILABLE`、feature `roots`→`vaults`；远端协议 major 1→2、本机 IPC major 1→2（不兼容如实声明），生成代码由 `cargo xtask generate` 重出。
- 配置：段 `[roots]`→`[vaults]`（段内 `allowed_bases` 键保持不变），Rust 字段 `allowed_root_bases`→`allowed_vault_bases`；主机部署配置需同批更新，S142 落实。
- 数据库：服务端迁移 `0016_vault_rename.sql`（`roots`→`vaults`、各 `root_id`→`vault_id`、`root_seq`→`vault_seq`、`deletion_root`→`deletion_vault`、4 个索引重建，schema 15→16）；客户端迁移 `0013_vault_rename.sql`（`bindings.root_id`→`vault_id`）。历史迁移 0001—0015（服务端）与 0001—0012（客户端）不改写，旧名字仅保留在冻结迁移中。
- 磁盘布局：对象区前缀仍为 `roots/<vault_id>/objects/...`（S136/ADR-020 已落地），不搬迁已发布对象；以 `ObjectLayout::SCOPED_PREFIX` 常量与注释固定，备份校验、Web 备份清单校验同步保持 `roots/`。

改动路径：`crates/*`（domain、protocol、server-store、server-core、client-store、agent-core、planner、http-client、fs-common、platform-linux-server、platform-windows）、`apps/*`（server、server-admin、agent、cli、web 源码、desktop 壳）、`packages/*`、`api/openapi.yaml`、`api/local-ipc.schema.json`、`api/examples/*`、`tests/contract/upgrade/*`、`tests/server-integration/*`、`tests/e2e/src`、`tools/*`、`deploy/*`、`nix/modules/*`、`packaging/*`。生成文件仅由 xtask 重出，未手改。

- `cargo xtask generate --check`：5 个生成文件与磁盘一致。
- `pnpm install --offline --frozen-lockfile`、`pnpm --recursive run typecheck`、`pnpm --recursive --if-present run test`（含 api-client/local-ipc-types schema decoders 与 apps/web 七个 node 测试）exit0。

限制与未覆盖：

- Windows 原生（CFAPI、Explorer、安装包、CLI/GUI 原生运行）未在本卡重跑；`platform-windows` 仅宿主编译/单测覆盖。S141 负责 Windows 客户端原生复验。
- `apps/web/tests/*.mjs` 与 `tests/platform/windows/s08*-webview.js` 已随源码改名并通过 node 测试；真实浏览器（`tests/web/*.py`）与 Windows 原生 WebView 验收仍需 S141/S142 执行。
- 未部署生产。线上仍是 S138/S139 源与 schema15；S142 部署前必须先备份，再执行 15→16 迁移、更新主机 `[vaults]` 配置键、同批替换 Windows 客户端。
- 物理对象布局未改名（见 ADR-021），备份与恢复继续识别 `roots/` 前缀。
