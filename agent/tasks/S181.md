# S181 取消密码最短长度限制，并把本机管理员密码重置为 `1`

用户要求（2026-11-10）：“将服务端管理员的密码重置为 1，并取消密码的限制（如最短长度）”。
经确认保留的底线是**只要求非空密码**（1 字符即可，空串仍拒绝），重置走**一次性离线改库**，不新增管理命令。

## 接口与实现

- `crates/server-core/src/auth/init.rs`：`MIN_PASSWORD_CHARS` 12 → 1，`validate_password` 只看非空与 1024 字节上限；
  错误文案改为“密码不能为空”。Argon2id 参数（`m=19456,t=2,p=1`）、PHC 格式、登录限流、改密撤销会话均不变。
- `crates/server-core/src/auth/manage.rs`：改密沿用同一校验；测试改为空新密码被拒、单字符新密码可散列并校验通过。
- `apps/server/src/auth/manage.rs`：`POST /v1/auth/password` 的 400 文案改为“新密码不能为空且不超过 1024 字节”。
- `apps/web/src/features/auth/Auth.tsx`：改密表单 `minLength` 12 → 1，说明文字去掉“至少 12 个字符”。
- 文档：`docs/design.md` §24 新增 ADR-031 决定记录（含弱口令风险与替代方案说明），
  `docs/architecture/interfaces.md` 的 `prepare_owner` 契约同步为 `MIN_PASSWORD_CHARS=1`。

## 限制与后续

- 有意接受弱口令风险：服务端只剩登录限流与 HTTPS 防护，本决定**不**代表首发安全门禁通过；
  Windows 桌面端登录框不校验长度，无需改动；客户端已保存的会话因全部撤销需重新登录。
- 生产库为手工离线改散列，未新增 `reset-password` 管理子命令；日后若需要在线/可审计的重置路径需另立卡。
