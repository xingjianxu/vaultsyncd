# S064-b — 恢复导出

状态：done。`ExportRecovery` 通过平台端口把当前未确认内容与固定上传快照分别保留，文件名仅 kind+EntryId/OpId。state.json 保留绑定身份/epoch/模式/游标、基线、队列、意图、受控动作、重建分类和隔离操作；不输出上传会话token。输出逐文件流式读回校验大小/SHA-256，复核来源、数据库和新增候选后才写manifest，最后持久化并再次validate。validate拒绝缺state/非法身份/来源与文件名不符/摘要或绑定不符。失败不清dirty、不覆盖用户数据，不把部分包宣称成功。

目的端口负责安全祖先句柄、create_new、禁止reparse跟随、保留目录身份、禁止与同步/缓存目录重叠；生产Windows适配由应用入口实现，本卡没有把Linux测试适配器当产品。固定快照缺失、部分内容不可恢复或根不可访问时明确失败，保留部分目录供人工取回，未实现自动恢复/覆盖安装。测试端口真实SQLite/磁盘覆盖静态路径穿越、symlink、同名不覆盖、篡改、源变化与导出时新增候选；并发目录替换安全属于平台端口必须验证的实现契约。
