## 接口与实现

- 新包 `apps/cli`（`vaultsyncd-cli`，产物 `vaultsyncd-cli.exe`）只依赖 local-ipc、platform-windows、Tokio、rpassword、rand_core；`cargo tree -p vaultsyncd-cli` 无 client-store、SQLx、agent-core。命令映射全部 21 项 1.2 命令：`status`、`subscribe-status`、`connection`/`set-connection`/`login`/`logout`、`roots`、`bindings`/`create-binding`/`pause`/`resume`/`mode`/`detach`、`download`/`release`、`problems`/`retry`、`history`/`trash`/`restore`、`export-recovery`。`download`/`release` 缺省生成规范 32 位十六进制 `operation_id`。
- `--json`/`-j` 输出单行信封：成功 `{ok,command,result}`，失败 `{ok:false,command,error:{code,message,retryable},exit_code}`。成功应答缺关键结果时以 `protocol_error` 失败，不把缺失结果当空列表/成功。
- 稳定退出码：0 成功；2 用法/输入错误；3 无法连接 agent；4 未登录/需重新认证；5 agent 拒绝或执行失败；6 协议/应答不兼容。
- `login --username` 的密码只从终端安全输入（rpassword 不回显）或 stdin 首行读取；`--password` 明确拒绝。密码不进入 argv、shell 历史、JSON、stderr 或日志。
- agent `management_response` 修正两处分类：`AUTH_EXPIRED` → `unauthenticated`（错误密码/过期会话不再误报 blocked）；`BINDING_UNBOUND` → `blocked`（已解绑后恢复/切模式不再落入 unavailable）。CLI 依赖此稳定分类输出退出码 4/5。
