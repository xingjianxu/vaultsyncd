## 实现与接口

「同步目录」只保留添加按钮，点击后挂载 Mantine Modal 及原有按服务器读取授权 Vault/目录选择/模式表单；取消、X、Escape/遮罩不创建，重开重置，忙时禁止关闭/重复提交，成功后关闭，失败保留输入。暂时 IPC 断连保留草稿且禁用提交，弹窗内可检查本机连接，避免失败刷新清空草稿。服务器或认证实际变更仍按上下文隔离。

Binding 第一列路径为可键盘激活的 button。`AgentClient.openBindingDirectory(bindingId)` → Tauri `open_binding_directory {bindingId}` → 认证 GetStatus 的活动 `management.bindings` → Windows `StorageFolder` → `Launcher::LaunchFolderAsync`；只接受绑定身份，不透传任意路径/命令，不执行目录内文件，错误沿既有反馈。接口见 `docs/architecture/interfaces.md` S081；本机 IPC/远端协议/schema 无变化。无服务端产物变化，不部署 prod/dev、不发行。
