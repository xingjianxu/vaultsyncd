# S065-b — 原生监视、补扫及 Windows 验收

状态：done；父卡 S065 的监视/验收部分。

`watcher/{mod,native}.rs` 实际调用 `ReadDirectoryChangesW`，持有固定地址 OVERLAPPED/缓冲区，限时 poll，drop 取消并等待完成后再释放内存。根以已 pin 父句柄相对重开并核对身份，不依赖文本路径。通知只有线索；零字节/ERROR_NOTIFY_ENUM_DIR、畸形记录及丢失监视分别产生 Rescan。过滤器排除 last-access，避免元数据补扫自触发反馈。`ReconcileGate` 启动/提示后全扫，周期兜底；不健康扫描不清围栏。

`run-native-files.sh` 在 windows devShell 交叉构建真实 Rust 测试 harness（静态 CRT），传送并核对 SHA-256，再通过既有 SSH 执行。客体原生用 64 B 内核缓冲产生真实溢出，完整扫描恢复 400 文件，恢复通知可用且 drop 有界；根权限失效报告 WatchLost/RootUnavailable，子目录 ACL 失败整轮不授权删除。CFAPI 三个占位符扫描前后均 `on_disk_data_size=0`，没有下载全盘。所有 run_id 目录/临时盘符和 CFAPI 注册均清理，VM 在线。最终验证与 hash 见 S065。
