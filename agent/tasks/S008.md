## 3. 限制与未核验项

- 评估版 90 天期限（非产品授权）；到期行为未验证。
- hostfwd 只能绑 `0.0.0.0`，宿主有公网地址且主机防火墙放行全端口：靠密钥独占认证收敛，客体不运行时关闭端口。真实 LAN/公网扫描未验证。
- 沿用 quickemu `EnableLUA=false`（UAC 关闭）、`secureboot=off`，与生产 Windows 不同。
- qemu-ga 服务在客体 Running，但宿主 `windows-11-agent.sock` 上 `guest-ping` 无响应；备选通道以 WinRM 为准。
- `DODownloadMode=0` 生效，但 `dosvc` 启动类型仍显示 `Automatic`，未进一步排查。
- 按 ADR-013 客体**未安装**任何编译工具链；交叉编译与宿主产物交付属 S009。
- 第二台客体/并发（S107）未执行，只生成了基线归档。
- 未验证：BitLocker、Secure Boot 开启、评估版到期、CFAPI（S010—S012）。
