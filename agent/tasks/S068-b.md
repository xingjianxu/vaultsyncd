# S068-b — 可恢复的 Windows 受控发布

状态：done；父卡 S068 的平台 publication 子范围。接口映射与实际验证见 S068。

原生能力试验证明：目标 share-none 句柄仍在时，即使 FileRenameInformationEx 的 POSIX 标志也不能直接替换，错误 32；不关闭保护后裸 rename。正式序列：应用先提交 core local_intent，平台准备私有固定 stage并保护下复核摘要/物理身份 → 创建同 OpId 平台日志并 FlushFileBuffers → 在持续保护句柄上将旧对象移入独立 state 的 preserved 文件 → 不覆盖发布 stage → 复核后返回 → 应用成功提交 baseline 后确认清平台日志。旧对象、固定快照不自动删除。

这是一套含可恢复中间态的两段发布，不宣称一次原子 rename。启动必须先调用 `recover_publications` 再运行 core recovery/同步；记录绑定根物理身份及前后物理身份/摘要。目标缺失且备份仍为原对象时，保护并恢复旧对象；已发布须后物理身份与完整摘要均一致；用户在间隙创建目标或第三种内容时保三方并 Blocked。解析/路径/根身份异常保日志报错。同 OpId 重试复用 stage与日志，不重复保存旧副本；新保存不能被旧日志覆盖。

独立 Windows 测试子进程在保全后/发布后/清日志前分别直接退出 121/122/123，由另一个进程/句柄重新打开恢复。验证新旧字节、日志、第三方占位与损坏路径，未把正常析构当中断。验证的是进程中断；突然掉电的硬件持久性仍需后续故障矩阵。普通文件输出的 CFAPI 身份安装由应用按 committed Entry/Version 完成，平台不从文件内容猜业务身份。
