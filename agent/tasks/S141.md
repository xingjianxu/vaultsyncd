## 复验中发现并修复的改名/升版遗留故障

原卡“`cargo xwin check --workspace --all-targets` exit0”的结论不成立：在本基线上该命令实际失败，且多条原生入口无法运行。机械改名（S140 `root`→`vault`）误伤非概念标识符，IPC major 1→2 后仍有多处硬编码版本：

1. `tests/platform/windows/s114-picker.ps1`：`AutomationElement::RootElement` 被改成不存在的 `VaultElement`，目录选择器自动化抛空引用，`run-native-bindings/files-ui/history` 三条入口全部失败（`timeout native selection`）。
2. `tests/platform/windows/s109-zip.ps1`：`IsPathRooted`/`GetPathRoot` 被改成 `IsPathVaulted`/`GetPathVault`；`tests/platform/linux/run-admin-socket.py` 的 sshd `PermitRootLogin` 被改成非法关键字 `PermitVaultLogin`（sshd 会拒绝启动）。
3. `apps/agent/tests/native_process.rs`、`tests/windows-integration/src/bin/agent_lifecycle_smoke.rs`：`CredentialVault` 句柄与改名后的 `vault` 路径/ID 变量同名遮蔽，`x86_64-pc-windows-msvc --all-targets` 23 处类型错误。
4. IPC 版本硬编码：`apps/agent/src/maintenance.rs`（major 1）、`apps/agent/src/portable.rs`（1.5）、`apps/agent/tests/native_process/management_native.rs`（1.2）、`tests/windows-integration/tests/unuploaded_recovery.rs`（1.4）在 agent 支持 2.6 后被 `UnsupportedVersion` 拒绝；改为 `version::supported()` / 生成常量 `PROTOCOL_MAJOR`/`PROTOCOL_MINOR`。`crates/platform-windows/src/ipc/tests.rs` 的“未知命令”帧也改用当前版本，避免因版本被拒而误判。
5. `run-native-write.sh` 缺少 ACL 用例所需的临时第二本机用户，74 项里稳定 1 项失败；改为按 S071 同法创建临时用户并在 `finally` 删除。
6. `s082/s083` webview 在绑定 `option` 尚未加载时给 `select` 赋值会被丢弃；改为先等目标 `option` 出现。
7. S114 把本地目录改成只读字段 + 原生文件夹选择器后，`s099-installation.*` 仍直接 `fill` 只读输入框（60 s 超时）。改为在测试用户会话内由 worker 启动同一份 `s114-picker.ps1`（新增 `-SelectOnly`），Python 侧点击“选择目录…”并等待只读字段回填。选择器还需处理客体会话的“前台锁”：诊断到前台被 `SearchHost` 的 Search 浮层占用，`SetForegroundWindow`/`AttachThreadInput`/`SwitchToThisWindow` 均失败，最终用“先 ESC 收起浮层 + 真实点击对话框标题栏”取得前台。
