## 接口决定

- 新增 `agent-core::engine::events::EventReceiver<S,D,A>`。`ChangeSource` 按 Root、after、limit 拉取生成的 `ChangeList`；`EventDecoder` 同时处理 wire 批次和重启后 `received_changes` 原始数据，未知事件不能静默变成空任务；`EventApplier` 负责按显式依赖独立推进无关任务。
- 接收阶段调用 `client_store::events::receive_batch`，批次、remote、pending tasks、received cursor 在一个短事务内写入；提交后才应用。
- 应用阶段成功后另开短事务写 `baseline_entries` 并调用 `mark_batch_applied`；失败只标记 `blocked`，不删除批次、不提前推进 applied cursor。启动/周期运行先 `resume_pending`，SSE/SeqHint 只作唤醒，`run_cycle(None)` 周期 pull 兜底；严格拒绝 changes 页空洞、乱序和错误 Root。
- `http-client::changes::list` 接入 S048 changes JSON 端点；`ApiRequest` 提供独立查询参数编码，禁止把查询串直接拼入路径。
