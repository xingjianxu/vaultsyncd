# S114-b — 远端 Root 名称链路

状态：done，父卡 [S114](S114.md)。范围为可选 RootSummary.name 的 schema、生成、服务端及 agent 消费。

只在 api/openapi.yaml 添加可选 name，再 cargo xtask generate；服务端从已授权注册路径取末级目录名，root_id、稳定排序和授权不变；agent 使用该名，缺名/空名提示更新服务端。无数据库迁移与 IPC 变更，老客户端可忽略新字段，老服务端缺字段可正常反序列化。

protocol 20 项、Root HTTP 6 项通过，包含中文/空格同名目录的不同身份、父路径和其他 owner 隔离；Windows 及宿主 clippy、生成5文件一致与消费者边界通过。真实 Windows WebView 报告 rootNameDisplayed=true，绑定按原 root_id 创建且首合并通过；最终报告、提交与工作树整合统一见父卡。
